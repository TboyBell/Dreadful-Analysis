# Module 4 — DAM106 Database

## Loan Application Tracking System

This project focuses on the design of a relational database for a loan application tracking system.

The main technical focus is **database modelling and relational schema design** rather than the business scenario itself.

The project demonstrates the process of translating requirements into a structured data model:

```text
Business Requirements
        │
        ▼
Identify Entities
        │
        ▼
Define Attributes
        │
        ▼
Primary Keys
        │
        ▼
Foreign Keys
        │
        ▼
Relationships
        │
        ▼
Cardinality
        │
        ▼
Normalisation
        │
        ▼
Entity Relationship Diagram
        │
        ▼
Relational Data Model
```

### Technical Areas

The project demonstrates experience with:

- relational database design
- logical data modelling
- entity identification
- attribute modelling
- Entity Relationship Diagrams
- primary keys
- foreign keys
- relationship cardinality
- referential integrity
- database normalisation
- schema design
- Visual Paradigm

The database model was designed using **Visual Paradigm**, with the ERD used to communicate the structure and relationships within the proposed system.

### Key Competencies

`Database Design` · `Data Modelling` · `ERD` · `Visual Paradigm` · `Normalisation` · `Primary Keys` · `Foreign Keys` · `Cardinality` · `Referential Integrity` · `Relational Databases`

```text

      │
      ▼
Data Inspection
      │
      ▼
Python Cleaning Pipeline
      │
      ▼

      │
      ▼
Exploratory Data Analysis
      │
      ▼
Statistical Investigation

      ▼

      │
```

```text
Python
│
```

The project demonstrates experience with:

- Pandas DataFrame manipulation

- data-quality assessment
- CSV processing
- exploratory data analysis
- grouping and aggregation
- categorical analysis
- temporal analysis
