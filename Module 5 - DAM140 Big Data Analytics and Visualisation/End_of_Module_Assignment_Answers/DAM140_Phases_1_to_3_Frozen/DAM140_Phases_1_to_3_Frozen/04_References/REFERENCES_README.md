# References

## Available as an actual file in this workspace

**`BOOK_Chapter_Springer_ABID.pdf`**
Abid, F. and Izeboudjen, N. (2020) 'Predicting Forest Fire in Algeria Using
Data Mining Techniques: Case Study of the Decision Tree Algorithm',
*Advances in Intelligent Systems and Computing*, vol. 1105, pp. 363–370.
https://doi.org/10.1007/978-3-030-36674-2_37

Supports: dataset composition (244 instances, 122 per region), the 138
fire / 106 not-fire class counts, and — critically — the confirmed
statement (p. 367) that the class designation was constructed using the
FWI and FFMC components rather than independently observed fire incidents.

## Cited but NOT available as files in this workspace

The following were used as citations (verified via web search where noted
in the analysis, or from general domain knowledge for the two long-standing
technical sources) but no PDF or document copy of them was ever supplied to
or retrieved by this workspace. They are listed here for completeness of
the reference list, not included as files, per instruction not to fabricate
or recreate unavailable papers:

- **Van Wagner, C.E. (1987)** *Development and Structure of the Canadian
  Forest Fire Weather Index System*. Forestry Technical Report 35. Ottawa:
  Canadian Forestry Service. — supports the structure of the FWI system,
  its weather inputs, and the cumulative/carry-forward nature of DMC and DC.
- **UCI Machine Learning Repository** dataset documentation for "Algerian
  Forest Fires" (Abid, F. (2019), https://doi.org/10.24432/C5KW4N) —
  supports basic dataset facts (instance counts, attribute ranges,
  variable definitions).
- **Romano, J., Kromrey, J.D., Coraggio, J. and Skowronek, J. (2006)**
  'Appropriate Statistics for Ordinal Level Data...', paper presented at
  the Annual Meeting of the Florida Association of Institutional Research.
  — supports the Cliff's delta magnitude thresholds used throughout Phase 3
  (negligible/small/medium/large).
- **Lamri, M., Sahour, A., Boumehrez, F. and Bekhouche, A. (2025)**
  'Comparative Analysis of Wildfire Prediction Models Across Climatic
  Regions...', *Traitement du Signal*, 42(3), pp. 1219–1241.
  https://doi.org/10.18280/ts.420302 — **analyses the same UCI dataset used
  in this project. It is cited only as a prior analysis of the same data
  that motivates examining regional heterogeneity, NOT as independent
  climatic validation.** No independent (non-dataset-derived) climatological
  source was found strong enough to cite in its place; commercial weather-
  aggregator sites checked during Phase 3 disagreed with each other on the
  regions' climate classification and were judged unsuitable.

If you have direct access to any of the four sources above, adding the
actual PDF/document to this folder would strengthen the package.
