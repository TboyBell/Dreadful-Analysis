# Original Data - Untouched Source

This folder contains the exact, unmodified dataset ZIP as originally supplied
for this assessment: `algerian_forest_fires_dataset.zip`
(contains `Algerian_forest_fires_dataset_UPDATE.csv`).

**This file must not be edited, cleaned, or overwritten.** It exists only as
the original reference copy. All cleaning was performed on a copy, with the
process documented in `02_Phase_2_Cleaning_Frozen/`. If in doubt about
whether a "clean" dataset is correct, this file is the ground truth to
re-derive it from.
